## 3. Linting & Formatting

### Current Status: **CONFIGURED** ✅

- ✅ **Biome** v2.5.10 (`biome.json`) — combined lint + format, replaces ESLint + Prettier
- ✅ No residual diagnostics on `src/` and `tests/unit/`
- ✅ npm scripts: `lint`, `format`
- ❌ No EditorConfig
- ❌ No husky/pre-commit hooks

### Corrections Applied by Biome

- `useTemplate` → template literals instead of string concatenation
- `parseInt` → explicit radix 10
- `useIterableCallbackReturn` → fixed `forEach` callbacks (no implicit return)
- Removed unused imports/variables
- Automatic formatting (2 spaces, no unnecessary parentheses)

### Why Biome and not ESLint?

Biome is a modern (Rust-based) tool that combines **linting + formatting** in a single tool:
- **10x faster** than ESLint + Prettier
- **Zero config** by default (reasonable conventions)
- **All-in-one** — no need to manage ESLint + Prettier + eslint-config-prettier
- Clear diagnostics and powerful auto-fix
